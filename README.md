# MyBudgetBook — تطبيق ميزانية شخصية

مشروع Android كامل مبني بـ Kotlin + Jetpack Compose + Room، مستوحى من مخطط قاعدة البيانات الأصلي، ومصمم ليطابق الواجهات المرفقة.

## ✨ الميزات المنجزة

- **إضافة معاملة**: تبويبات (مصروف، دخل، تحويل)، آلة حاسبة (Keypad)، حقل "ملاحظة" (`notiz`)، العملة، ورقم الحوالة.
- **إدارة الحسابات**: عرض الأرصدة الديناميكية، إضافة/تعديل/حذف حساب، وفرز متقدم.
- **المعاملات**: قائمة الحركات مع مجاميع الرصيد والدخل، وتصميم داكن.
- **الإحصائيات**: تجميع الدخل والمصروف حسب الفئة.
- **التقويم**: شبكة شهرية تعرض حركة كل يوم.
- **الميزانيات**: إنشاء ميزانية ومتابعة شريط التقدم (Progress Bar).
- **الفئات**: شجرة فئات قابلة للطي مع شريط بحث.
- **المعاملات المتكررة والقوالب**: شاشات مخصصة لعرضها.
- **القائمة الجانبية**: تنقل سلس بين جميع الشاشات.

## 🚀 كيف تفتحه

1. فك ضغط الملف.
2. افتح **Android Studio** (Ladybug أو أحدث).
3. `File → Open` واختر مجلد `MyBudgetBook`.
4. انتظر Gradle Sync.
5. اضغط **Run ▶**.
